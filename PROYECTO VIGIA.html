Proyecto VIGÍA

Una colaboración entre CMPC y FIDES Consulting

Visión Estratégica: Proyecto VIGÍA

VIGÍA: Visualización e Inteligencia para la Gestión de Índices de Amenaza.

La visión del proyecto se centra en crear un sistema de gestión proactiva para detectar, evaluar y mitigar los riesgos de incendios antes de que escalen. Un "vigía" es un centinela que observa y alerta ante el peligro. Este concepto representa la misión de monitorear constantemente para anticipar y proteger el patrimonio de CMPC, pasando de un modelo reactivo a una inversión estratégica en prevención.

El Problema

CMPC enfrenta anualmente la amenaza de incendios en sus plantaciones, generando enormes costos en combate, pérdida de patrimonio y daños a la infraestructura y al medio ambiente. La falta de una gestión proactiva y sistemática de los peligros es un factor clave que agrava el riesgo.

La Solución Propuesta

Una plataforma centralizada (web y móvil) que permite al personal en terreno reportar riesgos georreferenciados (tendidos eléctricos, quemas, etc.) con una app. El sistema evalúa, prioriza y asigna tareas de mitigación, permitiendo un monitoreo en tiempo real a través de dashboards.

Metodología y Piloto

Se propuso un trabajo de co-desarrollo, combinando la experiencia de CMPC con la expertise tecnológica de FIDES. Para validar el concepto, se ofreció un programa piloto gratuito de 3 meses en un área geográfica definida, para probar la funcionalidad, recoger feedback y demostrar el valor de la herramienta antes de un despliegue a gran escala.

Detalles del Proyecto en Ejecución

Este proyecto consiste en el desarrollo de una solución tecnológica integral para prevenir incendios forestales. La iniciativa, liderada por FIDES Consulting para CMPC, busca transformar el enfoque reactivo de combate de incendios a uno preventivo y estratégico. Se abordan dos líneas de trabajo paralelas: 1) La optimización y escalabilidad del sistema de registro de actividades que ya utilizaba Giovanni González, y 2) El desarrollo del nuevo aplicativo VIGÍA para la gestión de riesgos y peligros de incendios.

Solución Técnica

La solución se basa en migrar y potenciar las herramientas existentes de CMPC a una plataforma profesional con todas las capacidades de Google.

  • Aplicativo: AppSheet con funcionalidades avanzadas.
  • Base de Datos: MySQL en Google Cloud para manejar grandes volúmenes de datos.
  • Optimización: Mejora de eficiencia, reducción de tiempos de sincronización y solución de latencia.
  • Integración: Conexión segura a Power BI a través de una IP fija.

Requerimientos y Mejoras (CMPC)

Se han incorporado las siguientes oportunidades de mejora solicitadas por CMPC para fortalecer el sistema:

  • Módulo de Riesgos (Georef, fotos, nivel).
  • Validación de aperturas de recursos.
  • Mejoras en sincronización y gestión de turnos.
  • Notificaciones de alerta para actividades.
  • Gestión de actividades de combate.

Beneficios para CMPC

  • Ahorro de Costos: Prevenir es más eficiente que combatir.
  • Sistema Sólido: Plataforma centralizada para la prevención.
  • Toma de Decisiones: Datos ordenados para análisis estratégico.
  • Crecimiento del Personal: Foco en análisis en vez de gestión de datos.
  • Escalabilidad: Potencial para extender el sistema a colaboradores externos.
